# 完形填空方法：语篇逻辑破译、瞻前顾后与上下呼应

## 核心观念

完形依据整体语篇形成局部答案，课程用格式塔“整体感知”解释这一命题思路。做题不能只翻译空格所在短语，而要寻找作者已经给出的提示。

课程方法要点是寻找提示、按相同词性判断、先还原代词并补全缺失主语；这些只作为方法步骤讲解，不合并成口诀复述。

讲义将空格按线索范围分为词内、词间、句内、句间四类，难度大致递增，课程样本比例约为 `2:3:5:5`。该比例只用于理解命题分布，不用于硬套某套试题。

## 完整做题流程

### 1. 首句完整定主题，并建立叙事框架

先读通常完整的首句，确定：

- 核心人物或事物；
- 主要情境和主题词；
- 初始情感底色：积极、消极或中性；
- 叙述角度：谁在看、谁在感受、谁在行动；叙事类语篇要用课程“角色渗透法”进入主人公或主题对象的处境，不能站在读者事后视角替人物补动机；
- 写作顺序：顺叙、倒叙、插叙、补叙或分叙，明确当前句在事件链中的位置；
- 叙事要素：时间、地点、人物、事件、原因和结果，即 `5W+1H`；
- 写作目的：文章借叙事、写人或写景说明什么道理，给出什么启发。

后文出现转折时可以改变情感方向，但必须有文本信号。不要先入为主地把“正能量”当答案。

上述四项在叙事类完形中作为篇章准备使用；若原文不是叙事语篇，就只提取实际存在的主题对象、结构和写作目的，不生搬硬套人物或故事要素。

### 2. 扫选项，只判词性和差异

每组四项先看共同词性，再比较真正差异：动作方向、对象、情感、程度、搭配或上下义。无需在首遍背下所有词义。

### 3. 读语篇大意

按意群读，不逐词心译。长句用“劫匪插葱”：暂时拿掉介词短语、非谓语、插入语和从句，留下主语、谓语、宾语或表语，再把修饰信息放回。

遇到生词先用上下文、构词法和同义/反义线索推测；知道句子大意即可，不为一个词中断全文理解。

### 4. 对每空执行“相同词性定答案”

先确定选项共同词性，再找同词性或同功能提示：

- **动词**：看动作先后、因果、主客体搭配和行为链。谁做什么、动作作用于谁，往往比中文近义更重要。
- **名词**：看同一语义场、上下义、共指、原词/近义/反义/同根复现。
- **形容词、副词**：看褒贬、语气、程度和转折前后的情感变化。
- 其他词类：仍按其语法功能寻找平行、替代、指代或固定搭配线索。

### 5. 按由近到远寻找提示

1. 先看空格所在句内部；
2. 再看前一句和后一句；
3. 再扩大到本段；
4. 若没有直接提示，回到段尾升华或全文主旨，即“无信靠主旨”。

找到的必须是可说出的文本证据，如“后文 `returned` 与此处动作构成先后”“下一句的 `relieved` 说明情绪由负转正”，不能只说“凭语感”。

### 6. 难空先跳，第二遍回收

首遍没有明确提示的空先留着，避免一个空拖断整体理解。读到后文新增线索后再回填。最后才可谨慎用选项分布“配平”；配平不能替代语篇证据。

## 必做的语篇还原

### 代词先还原

把 `it/this/that/they/he/she` 等还原为具体人、物、动作或事实。选项若与真实指代对象不搭配，应排除。

### 主语缺失补完整

并列句、省略句和非谓语结构中，先补出动作发出者，再判断动词。避免把前一句宾语误当下一动作的主语。

### 否定看奇偶与范围

留意 `not, never, hardly, little, few, without, fail to` 等否定或半否定信号。检查否定次数及作用范围，区分部分否定、全部否定和双重否定。

## 常见线索关系

- 原词、同义词、近义词、反义词、同根词复现；
- 上下义与同一语义场；
- 时间顺序和动作链；
- 原因—结果、条件—结果、目的—手段；
- 转折、让步、并列、递进；
- 人物情绪或态度的转变；
- 固定搭配与主谓/动宾搭配；
- 首尾照应、主题回扣和段尾升华。

## 选项排除标准

- **对象错**：动作或品质属于另一个人/物。
- **逻辑错**：先后、因果、转折方向不成立。
- **褒贬错**：与语境情感相反，且无转折依据。
- **程度错**：选项过强、过弱或绝对化。
- **搭配错**：词义看似接近，但主谓、动宾或介词搭配不成立。
- **范围错**：局部信息被扩大为全文，或主题被缩成一个细节。
- **无提示**：只能“说得通”，却找不到文本呼应；优先选择有明确提示的一项。

## 口播讲解组织

刚拿到题目先完成首句定主题；叙事类语篇同时静默建立角色、叙事顺序、`5W+1H` 和写作目的框架，再扫选项、判断词性并读语篇大意。随后按原空号推进。暂时找不到明确提示的空，按本模块课程要求暂跳，等后文提供线索后第二遍回收；不预先按难易重新排列全部空。每个空必须承接篇章结果，再依课程顺序完整讲：

1. **点名方法并承接篇章**：自然说明这道题使用“相同词性定答案”“瞻前顾后”或“上下呼应”，并承接前面确定的主题、角色、事件进程或情感。只有整份口播最开头使用一次“同学”，后续各空不重复称呼。
2. **判断选项词性与差异**：说明四项共同词性，并比较动作方向、对象、语义场、褒贬、程度或搭配差异。
3. **按相同词性找提示**：动词看先后、因果和主客搭配；名词看同一语义场及同反义复现；形副看褒贬和程度。
4. **由近到远定位线索**：本句 → 前后句 → 本段 → 段尾或全文主旨；同时按需要还原代词、补全主语、核对否定范围。
5. **推出并排除**：说明提示与答案是同义、反义、因果、动作先后、褒贬或搭配中的哪种关系；指出其他项在对象、逻辑、程度、范围或搭配上为什么不合。
6. **回填或暂跳**：证据充分则回填验证；没有明确提示则说明暂跳，读完后第二遍回收，不用配平代替证据。

用户要求讲解整篇时，同一篇的每个空都执行第 1—6 步；不能因首句主题已讲过，就省略本空与主题或语境提示的具体联系。学生只问某一个空时，以该空的第 1—6 步为中心，并引用判断本空所需的主题和上下文；若上下呼应需要其他空已经确定的动作链、情感线或词义线索，可展示该关联信息并说明呼应关系，不展开无关空。

答案回填或暂跳决定完成后直接结束本题，不复述口诀。
