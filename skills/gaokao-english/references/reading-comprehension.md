# 阅读理解方法：文体路由、定位与篇章结构

## 使用边界

先在内部判断应用文、记叙文、说明文或议论文，再调用对应方法。文体判断只决定内部路线，最终口播直接从本题方法切入，不报告“这是某文体”及判断过程。

课程参考用时：应用文约 1 分钟，记叙文约 5—6 分钟（部分训练按 6—7 分钟），说明文约 6—7 分钟，议论文约 5—6 分钟。用时是训练目标，不是牺牲准确率的硬性截止线。

## C、D 篇内部路由与讲题逻辑

课程明确“三化法优先在 C、D 篇使用——定主旨和文章结构”。C、D 只是试卷位置，不是文体标签；必须先静默判断文章实际写法，再调用课程方法。**以下判断全部只作内部路由，不得在最终口播中输出“C 篇/D 篇通常是什么文体”“本文判定为说明文/议论文”或判断过程。**

### 第一层：三问法定框架

遇到 C、D 篇，尤其是话题生僻、表达晦涩时，先回答课程“主旨三问”：

1. **主旨是什么**：用一个核心名词和一个核心动作/观点概括。
2. **态度的褒贬是什么**：看形容词、副词、情态动词、否定及转折后的评价。
3. **文章结构是什么**：标清背景、主题、解释/论证、例子、结果、应用或建议分别在哪一段。

三问的结果只作为后续题目的共同底图，不单独写成“文体判断报告”。

### 第二层：三化法落实主旨

严格按课程顺序：

1. **化简首尾段**：读首尾段的首尾句；若第一段只是疑问、大片背景、贬义现象或人物背景且没有主题词，它不算真正的“首段”，向后找到主题第一次明确出现的位置。尾段通常是最后一段。
2. **化简段首句**：中间段优先看第一句；若第一句仍是承接背景或例子，再看该段最后一句的归纳。
3. **化简重复词**：结合主旨题选项找全文反复出现的主题词、同义词和评价方向。三化法核心是确认“主题词＋褒贬态度”。

主旨题在读文章前可以先看选项，用“重复”大胆假设；细节题首轮只读题干，避免四个选项提前干扰定位。读文章的目的，是用首尾、段首和重复词对假设小心求证。

### 第三层：静默文体分流

不要看 C/D 字母猜文体，要看全文在做什么：

- **说明路径**：中心任务是介绍事物、解释现象/机制、呈现研究或说明发展。常见结构为“引出话题 → 介绍现状或举例说明 → 原因/机制/结果 → 应用或未来发展”；结尾通常强调应用、影响或后续研究。使用说明文“三化法、倒三角结构、定位原文＋同义替换、分句结构法/劫匪插葱”。
- **议论路径**：中心任务是围绕问题展开讨论、评价不同观点或提出主张。常见结构为“问题/旧认识 → 转折后的中心观点 → 论据或例子 → 结论、建议”；结尾通常有明确观点或建议。使用议论文“三化法、重复—定位—逻辑、主客一致、褒贬一致和观点归属”。
- **记叙或应用路径**：若文章实际以人物事件推进，转入记叙文 `5W+1H`、顺藤摸瓜、左顾右盼和中心思想；若信息分块、标题明确，转入应用文定位阅读法。不得把说明文/议论文方法硬套。

一篇文章可以含有叙事开头、研究例子或人物引语；应按全文的中心任务路由，不能被局部例子带偏。

### 第四层：建立段落功能骨架

给每段只标一个主要功能：背景/问题、主题/观点、解释/机制、研究/证据、例子、转折/反方、结果/影响、应用/建议。重点识别：

- `A, but B`：A 多是背景、常识或旧认识，B 是作者真正推进的中心。
- 具体数字、人物、事件通常是例子或证据；向前找总起观点，必要时再看后文归纳。
- 说明文重视从现象或研究到应用/未来的推进；议论文重视不同观点的关系以及结尾主张。
- 同时出现作者、研究者和被引人物时，静默记录“谁说了什么、态度如何”，防止把他人观点偷换成作者观点。

### 第五层：按课程题型顺序讲解

先建立三问与三化框架。说明文、议论文若同时出现主旨题、细节题和猜词题，按课程顺序“主旨题 → 细节题 → 猜词题”推进：先用主旨约束后续判断，再定位细节，最后在已经明确的语境中猜词。其他设问按其实际题型调用对应课程方法。这个顺序来自篇章方法，不是按难易挑题；数字、专名等线索只用于定位取证，不能把阅读理解改成七选五式的“由易到难找突破口”。最后仍按原题号汇总答案。

应用文按定位阅读法处理，记叙文按“顺藤摸瓜”由前到后推进；它们不套用说明文、议论文的上述三题型顺序。

### 第六层：C、D 篇逐题讲解链

每道题按以下链条口播，不能只报定位句：

1. 点名本题课程方法和题号；只有整份口播最开头使用一次“同学”，后续各题不重复称呼。
2. 说明题干在问对象、动作、原因、态度、段落作用还是全文主旨。
3. 用名词/数字/专名/重复词定位到段落；主旨或结构题调用三化法。
4. 用“劫匪插葱/分句结构法”化简关键句，只保留与考点相关的主语信息和谓语逻辑。
5. 若关键句有学生可能不认识的稍生僻词，先判词性；能拆则讲前缀/词根/后缀，再用同反义、转折、并列、因果、释义、例子或指代推断本句义，并代回验证。若该词不影响答案，只说明大致褒贬或动作方向，不中断做题主线。
6. 用“名词定位、动词逻辑、形副褒贬”对照选项；若含引语，先核对观点归属。
7. 说明正确项的同义替换或上位概括，并逐项识别五大天坑。
8. 回到三问与段落功能骨架复核：答案不能与全文主题、态度或结构作用冲突。

## 通用底层方法

### 重复—定位—逻辑

1. **重复（大胆假设）**：题干、选项与原文的原词、同义词、上下义词和高频主题词提供可能方向。
2. **定位（小心求证）**：用具体名词、专名、数字、比较级/最高级、时间地点等回原确信息区间。
3. **逻辑（化简句子）**：看主语与谓语、动作对象、因果、转折、并列和褒贬，不能只凭关键词重合。

课程第一原则：**名词定位，动词逻辑，形副看褒贬。**

- 名词帮助找到人、物、地点、概念和范围。
- 动词决定谁做什么、先后与因果，是判正误的核心。
- 形容词、副词决定态度、程度和趋势。
- 长句用“劫匪插葱”抓主干；按意群读，不逐词翻译。

### 先比较选项：去同求异

四个选项若都提到原文内容，先圈共同信息，再比较不同点。重点检查：

- 主体不同还是动作不同；
- 主动发出与被动接受是否颠倒；
- 单数/复数、过去/现在、一次动作/持续趋势是否不同；
- 褒义、贬义、中性及程度是否不同；
- 并列、转折、因果、包含还是无关系。

## 应用文：定位阅读法

应用文常见广告、活动介绍、课程说明、招聘、旅行信息、书信等，信息分块清楚。

### 操作顺序

1. 看大标题判断总主题，看小标题建立信息分区。
2. 读题干并“题目倒推”：它要求找人物、地点、日期、价格、条件、特色还是来源/目的。
3. 圈定位词：数字、金额、时间、距离、大写字母、专有名词、比较级/最高级、否定词和条件限制。
4. 直接进入对应小标题或段落，读取定位句及必要上下文。
5. 对照题干限制逐项核对，再确认原词复现或同义替换。

### 高频处理

- 价格、人数、日期、距离：先定位数字，再按题目条件计算；不能看到同一个数字就选。
- `longest/closest/first/best/only` 等：收集比较范围内所有候选，再比较，防止漏掉对象。
- `special/different`：横向比较各分块，找唯一特征。
- 要求、资格、申请方式：定位 `require, must, should, eligible, apply` 等及其否定或例外条件。
- 文章来源/写作目的：综合大标题、小标题、受众和功能，不能由一个细节武断推断。

## 记叙文：顺藤摸瓜、左顾右盼、中心思想

### 先建故事框架

用 `5W+1H` 抓时间、地点、人物、事件、原因和结果。开头多交代背景，中间沿时间、空间或事件发展展开，结尾常给情绪、感悟或道理。

快速读法：首段、尾段和每段首句先定框架；再按题目定位精读。若以人为主，跟人物变化和品质；若以事为主，跟起因—经过—结果。

### 细节题：顺藤摸瓜 + 左顾右盼

- 题目通常随文章推进，可按由前到后的顺序处理。
- 划出题干与选项核心词，回忆故事结构，定位到具体段落。
- 找到疑似句后“左顾右盼”，查看前句和后句补足原因、结果、指代或转折。
- 正确项常是核心词原词/同义近义复现与语言简化；仍须核对主语和动作逻辑。
- `TRUE/NOT TRUE` 等综合细节题可用跳读法：名词定位、动词判逻辑，逐项取证。

### 主旨、推断、意图与人物品质：回到中心思想

- 首段法：看首段主旨句，尤其转折词后或破折号后的重心。
- 核心名词法：原词或同义词反复出现的核心人物、事物、目标。
- 合并法：概括各段作用并合并。
- 首尾呼应法：把开端冲突/愿望与结尾结果/感悟连起来。
- 人物品质必须由反复行为、关键选择和结局支持，并与全文主旨挂钩，不能用一次偶然动作定性。
- 推断只跨“有证据的一小步”；常理只用于补足言外之意，不能替代文本。

## 说明文与议论文：主旨大意和结构跳读

### 做题顺序与三化法

课程建议先做主旨题，再做细节题和猜词题，用主旨约束后续判断。

“三化法”用于抓中心：

1. 化简首尾段；
2. 化简各段首尾句；
3. 化简反复出现的核心词。

说明文更常沿时间、机制、发现到应用展开，结尾常强调应用或影响；议论文更关注讨论、论证，结尾常给明确观点或建议。这是常见结构，不可替代对原文的具体判断。

### 主题句位置

- 总—分—总、总—分结构：主题句多在首尾；首段若先给背景或问题，主题句常在首段后半或第二段。
- 有小标题：全文中心常在第一个小标题前的邻近位置；小标题共同指向上位主题。
- 平行并列结构：分别概括各段，再合并全文大意。
- 高频核心词对 `best title/heading` 尤其重要；标题应含主题对象和核心动作/观点。

### 中心如何被引出

- `A, but B`：A 常是背景、常识或旧观点，转折后的 B 才是作者真正推进的中心。
- 举例引出：例子具有数字、具体人物和事件等具象特征；应向上找例子证明的抽象观点。
- 问题—解释—方案、现象—原因—影响、研究—发现—应用等结构，先标每段作用再判主旨。

### 例子题与“双主旨”

- 问“为什么提到某人/某事/某例子”时，优先看例子前的总起观点，其次看例子后的归纳，不把例子本身复述成作用。
- 主旨题中例子通常不是答案；细节题若正好问例子，则必须按原文取证。
- 若看似有两个主题，判断谁为谁服务：通常一个上位主题统摄多个例子或子话题，“双主旨本质仍要归为单主旨”。

### 主旨选项判断

- 正确项应覆盖全文主体、核心动作/观点和合适范围。
- “大词原则”只能在选项比较且文本确有包含关系时使用；大而空、超出文章范围仍是错项。
- 段落主旨可用“并列删除”：删除并列细节，保留共同上位概念。
- 最佳标题在准确覆盖主旨的前提下可以更凝练、有吸引力，不能只求新颖。
- 犹豫时用“选项倒推”：若此项真是标题/主旨，全文各段是否大体都应为它服务？

## 常见题型的取证方式

### 细节理解

题干关键词定位 → 读定位句及前后句 → 核对主体、动作、范围、条件、时间和程度 → 确认同义替换。

### 推理判断

只推出原文必然或高度支持的一步；区分事实、作者评价和读者想象。答案不能比证据更绝对、更宽或更远。

### 词义/句意猜测

先判词性及句中作用，再用同位解释、定义、举例、转折、因果、同反义和上下文行为结果猜测；将候选义代回原句验证。代词题必须先还原指代。

### 观点态度

找评价性形容词、副词、情态动词、引语归属和转折后的表态。区分作者态度、研究者观点和文中人物看法。

### 写作目的或段落作用

先概括该段写了什么，再看它与前后段的关系：引出主题、提供背景、举例证明、解释机制、形成对比、给出结果或提出建议。

### 下文预测

只接当前结尾尚未展开的方向；已在前文完成的内容不再重复，预测内容须与全文主题和段落推进一致。

## 阅读错误选项：先看五大天坑

1. **褒贬不一致**：形容词、副词或评价方向与原文相反。
2. **主客不一致**：偷换主语、对象，或颠倒动作发出者和承受者。
3. **动静不一致**：时态、一次动作与持续状态、趋势与结果不一致。
4. **因果倒置**：倒因为果、强拉因果，或把相关性说成因果。
5. **过度推测**：超出就近证据，引出原文没有的后果、动机或评价。

同时检查：

- 片面/以偏概全；
- 无中生有；
- 画蛇添足（主体和大意似乎对，但多加条件，或扩大/缩小范围）；
- 绝对化；
- 偷换概念；
- 单复数、比较范围和数量条件不一致；
- 与全文主旨相反或缺失核心主题。

“画蛇添足”等只能作第二层排除。第一层仍是名词定位、动词逻辑和原文取证。

## 口播讲解组织

刚拿到题目先按课程要求查看题干及相关选项，完成篇章准备后按本模块课程顺序讲解，不按难易重排。应用文按定位阅读法推进，记叙文按“顺藤摸瓜”由前到后处理；说明文/议论文先在内部用三化法建立主旨框架，若主旨题、细节题和猜词题同时出现，就按“主旨题 → 细节题 → 猜词题”讲解，其余题型调用各自取证方法。文体和篇章框架只在内部判断；每道题必须调用对应的课程子方法并按序讲：

1. **点名本题方法**：应用文说定位阅读法及具体定位信号，记叙文说顺藤摸瓜、左顾右盼或中心思想，说明文/议论文说三化法、重复—定位—逻辑、结构分析法等。不能只说“根据原文”。只有整份口播最开头使用一次“同学”，后续各题自然衔接。
2. **明确题干任务**：细节、主旨、推断、猜词、态度、写作目的、段落作用或下文预测，并据此选择本模块相应取证方式。
3. **按课程路径定位**：圈题干核心名词、数字、专名、比较词等，给出原文证据区间；应用文按大标题/小标题→题目倒推→定位信号，记叙文承接 `5W+1H` 和故事框架，说明文/议论文承接三化法与篇章结构。
4. **化简证据并判逻辑**：使用“名词定位、动词逻辑、形副褒贬”，必要时用“劫匪插葱”抓主干，说明主体、动作、因果、转折、范围和程度。
5. **对照选项**：说明正确项如何原词或同义替换；逐项点出错项属于褒贬不一致、主客不一致、动静不一致、因果倒置、过度推测、画蛇添足等哪一种。
6. **回原文验证**：核对题干限制和证据范围，确认结论后直接结束本题，不复述口诀或课程句。

用户要求讲解整篇时，同一篇的每一道选择题都执行第 1—6 步。文章框架可以只建立一次，但每题必须明确说明本题如何利用该框架完成定位和判断。学生只问某一道题时，以该题的第 1—6 步为中心；文章框架、前后段和其他选项只保留支撑该题判断所需的部分。若课程方法需要借助其他题的定位结果或对篇章主旨的交叉确认，应展示必要关联并说明用途，但不汇总或完整讲解无关题目。
