# 微信英语 Bot 管理器 1.1.1

新增 Windows x64 安装包。下载安装 `WechatEnglishBotManager-Setup-1.1.1-x64.exe`；便携版仍然可用。

- 中文安装向导，自动创建桌面和开始菜单快捷方式。
- 默认沿用 `D:\bot\release`（没有 D 盘时使用当前用户程序目录）；升级请选择原安装目录。
- 升级保留账号、管理列表、图片、上下文与用量记录。
- 卸载移除安装器登记的程序文件，保留 `data` 和已解压的运行目录。
- 安装过程中可通过 Windows 的应用关闭提示退出占用文件的管理器；安装结束默认不启动 Bot。
- 新增安装、覆盖升级与卸载的数据保留回归检查，以及版本标签触发的 Release 构建流程。
- 安装前检查目标目录长度，避免安装成功后因 Windows 路径限制无法解压运行环境。

程序内置 Node.js 与桥接依赖；本机仍需安装并登录 Codex。本次主要更新安装与发布方式，答题和接管行为保持 1.1.0 的实现。

安装包尚未配置代码签名证书，Windows 可能显示“未知发布者”。发布附件中的 SHA256SUMS.txt 可用于核对下载文件。
